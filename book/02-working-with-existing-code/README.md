# Part 02 — Working with existing code

Most projects do not start from an empty repository. The code was inherited, or the project started before anyone
thought about tests. This part covers how to change such code safely: fixing a bug so it stays fixed, and modernizing a
system that is hard to modify.

## Who this part is for

Scientists and engineering managers who maintain decision-support software they did not write from scratch.
